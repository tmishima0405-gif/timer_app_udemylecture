# Timer App (Udemy Lecture)

A timer app built with HTML, CSS, and JavaScript.

## Features

- Stopwatch mode
- Countdown mode
- Lap recording
- Clock illustration (`clock.svg`)

## Files

- `index.html`: App layout
- `style.css`: UI styles
- `script.js`: Timer logic
- `clock.svg`: Clock image

## Usage

1. Open `index.html` in your browser.
2. Select `Stopwatch` or `Countdown`.
3. Use `Start`, `Pause`, `Reset`, and `Lap`.

## Countdown

- Set minutes and press `Start`.
- When time reaches 0, `Time is up!` appears.
